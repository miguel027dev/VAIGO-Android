PATCH VIENNA ANDROID v2.0

1. Extraia este ZIP na raiz do projeto VAIGO antigo, sobrescrevendo arquivos.
2. Execute: bash APPLY-VIENNA-PATCH.sh
3. Configure VIENNA_BASE_URL se o host de produção mudar.
4. No backend, use MOBILE_AUTH_RETURN_URI=vienna://auth/callback.

O script remove os arquivos Java/drawables antigos que um ZIP comum não consegue apagar.
